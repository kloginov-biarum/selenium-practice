# CineBook — приложение для практики Page Object Model

Многостраничное приложение без бэкенда (данные в `localStorage`).
Тематика — онлайн-бронирование билетов в кинотеатр.

## Как запустить

Открой `cinema_app/index.html` в браузере, либо запусти лёгкий http-сервер из корня проекта:

```bash
python3 -m http.server 8000
# открыть http://localhost:8000/cinema_app/
```

> Через `file://` всё работает тоже — приложение полностью клиентское.

## Страницы и навигация

| Страница | Файл | Что отрабатывать |
|---|---|---|
| Home (список фильмов) | `index.html` | поиск, фильтры (genre, age), сортировка, грид с карточками |
| Movie details | `movie.html?id=<id>` | детали фильма, выбор сеанса (дата + время + зал) |
| Seat selection | `seats.html?showtime=<id>` | интерактивная сетка мест, VIP/обычные/занятые, расчёт суммы |
| Checkout | `checkout.html` | большая форма с валидацией (имя, e-mail, карта, чекбоксы) |
| Confirmation | `confirmation.html?id=<bookingId>` | проверка финального экрана |
| Login | `login.html` | вход, ошибки валидации |
| Register | `register.html` | регистрация, валидация (username, email, dob, password match) |
| Profile | `profile.html` | таблица бронирований, фильтр по статусу, отмена брони |

## Локаторы для POM

Все важные элементы помечены атрибутом `data-test-id="..."`.
Также есть осмысленные `id`, `name`, классы — можно тренировать разные стратегии локаторов (CSS, XPath, by name, by id).

Примеры:
```python
# data-test-id
driver.find_element(By.CSS_SELECTOR, '[data-test-id="search-input"]')

# by id
driver.find_element(By.ID, 'genre-filter')

# by name
driver.find_element(By.NAME, 'cardNumber')

# карточки фильмов
driver.find_elements(By.CSS_SELECTOR, '[data-test-id="movie-card"]')

# конкретное место в зале
driver.find_element(By.CSS_SELECTOR, '[data-seat-id="E5"]')
```

## Сценарии для автотестов (идеи)

**Smoke / навигация**
- Главная открывается, шапка содержит логотип и пункты меню
- Клик по карточке фильма → переход на страницу фильма с правильным заголовком

**Фильтры и поиск**
- Поиск по подстроке отфильтровывает грид
- Фильтр по жанру/возрастному рейтингу
- Сортировка по rating / year / price
- Комбинация фильтров → результат / пустое состояние

**Бронирование (E2E)**
- Регистрация нового пользователя
- Логин под существующим пользователем
- Выбор фильма → сеанса → 2 мест (включая VIP) → проверка суммы
- Заполнение формы checkout → подтверждение → отображение брони в профиле

**Валидация форм**
- Пустые обязательные поля → ошибки под каждым полем (`*-error`)
- Некорректный e-mail / телефон / карта
- Password mismatch при регистрации
- Username/email уже существует
- Чекбокс terms обязателен

**Места в зале**
- Занятые места недоступны (`.occupied`, `data-occupied="true"`)
- Лимит 8 мест на бронь (alert)
- Сумма пересчитывается с учётом VIP-наценки (+$5)
- Кнопка "Proceed" disabled пока нет выбранных мест

**Профиль**
- Список бронирований сортируется по дате создания (по убыванию)
- Фильтр по статусу
- Отмена брони → статус меняется на cancelled, кнопка исчезает
- После отмены освобождённые места снова доступны для выбора в seats.html

**Защищённые страницы**
- `profile.html` без логина показывает empty state с ссылкой на login
- `checkout.html` без выбранных мест показывает empty state

## Очистка данных между тестами

В `setUp` теста делай:

```python
driver.get(BASE_URL + 'index.html')
driver.execute_script('window.localStorage.clear();')
driver.refresh()
```

## Структура `localStorage`

| Ключ | Содержимое |
|---|---|
| `cinema_users` | массив пользователей |
| `cinema_current_user` | username залогиненного пользователя |
| `cinema_bookings` | массив всех броней |
| `cinema_pending` | объект с текущим незавершённым бронированием (между seats.html и checkout.html) |

Можно прединжектить тестовых пользователей и брони через `execute_script` для ускорения тестов.
